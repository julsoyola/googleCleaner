Privacy Policy

Last updated: October 14, 2026.

GoogleCleaner is a Chrome extension for reviewing and filtering files and folders you own in Google Drive and moving user-selected items to Trash.

The extension accesses your Google account email address and display name, OAuth access tokens, and Google Drive metadata: item IDs, names, types, modification dates, sizes, and links. The display name is requested but not used. Document contents are not downloaded or read.

When the Vercel account chooser is configured, Google handles sign-in and account selection in its own window. The extension validates the returned OAuth state and uses PKCE to bind authorization codes to the sign-in request. A developer-operated authentication service hosted on Vercel exchanges codes and refreshes sessions with Google. It receives authorization codes, PKCE verifiers, and encrypted refresh handles, and returns access tokens. It does not receive Drive file metadata, file contents, or passwords. The service does not persist tokens or log request bodies or token responses in its code. Network requests are processed by Vercel as the hosting provider.

Access tokens and encrypted refresh handles are held in chrome.storage.session during the browser session, outside cleanup jobs. The service encrypts refresh handles using AES-256-GCM; handles expire seven days after issuance. Restarting Chrome clears the extension's session storage. Without the Vercel service configured, the extension uses Chrome's native chrome.identity.getAuthToken token cache instead. The extension never collects Google passwords or embeds the Web OAuth client secret.

Drive metadata and your search, filter, sorting, and selection choices are processed in the extension's memory. Cleanup jobs are stored on your device using chrome.storage.local. They include account email, a job ID, selected item IDs and names, timestamps, progress, attempt counts, errors, reauthorization messages, and results. Reauthorization messages may include the email of a different signed-in account.

Cleanup jobs and results remain locally until dismissed or replaced by a new job. Disconnecting does not clear them. Completed jobs can be dismissed in the extension; active or paused jobs must be completed before dismissal.

Drive API requests go directly to Google. They send authorization tokens, listing queries, pagination tokens, and selected item IDs with instructions to move those items to Trash. Google returns account information, file metadata, and API responses. The extension does not upload file names or its local results log. Clicking an item's link opens the destination supplied by Google.

The extension contains no analytics or advertising. The configured Vercel authentication service receives only the authorization data described above; file names, file contents, and cleanup results are not uploaded to it. User data is not sold, used or transferred for purposes unrelated to GoogleCleaner's functionality, or used or transferred to determine creditworthiness or for lending purposes.

GoogleCleaner's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

To disconnect, choose Disconnect in the extension's account menu. This first saves a user-disconnected pause for any active cleanup job and cancels its scheduled wake-ups, then clears the configured Vercel session from the browser (or removes the current native cached access token) and clears the popup's in-memory account and file state. No new requests to move items to Trash are sent while the job is paused. A request already sent may finish, and its result is saved. Progress and results remain stored locally. Reconnecting does not resume cleanup automatically: choose Resume explicitly after connecting with the same account. Disconnecting does not revoke Google's authorization or clear saved results. To revoke access, open your Google Account connections settings, select the extension's entry, and remove its access. Revocation prevents subsequent authorized requests but does not remove locally saved results.
